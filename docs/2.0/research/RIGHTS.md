# 原项目上游、资产与授权核验

日期：2026-11-14。状态：初步调查完成，发行授权尚未整体核清；本页不授予任何原作者权利。

## 原仓库与 fork

GitHub 元数据确认[目标 fork](https://github.com/the-lazy-me/yipiantian)的上游为[henjicc/yipiantian](https://github.com/henjicc/yipiantian)。本轮根目录及跟踪文件检索未发现覆盖整个游戏的 LICENSE；两仓库 API 的许可元数据均未给出仓库级许可，目标许可接口返回 404。已有 Godot 与项目技能许可证不能自动覆盖游戏代码和美术。

这一结果表示当前未取得充分许可依据，不证明不存在单独授权。后续需要核对上游 README、贡献历史、作者授权文件或用户已持有的协议，明确修改、商业使用、再分发和署名范围。不得自行给整个 fork 加 MIT/GPL 并声称解决权属。

[GitHub 官方说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)指出无许可证时通常保留默认版权；公开可见及可 fork 与允许任意分发不同。本轮只写策划与研究，不复制额外上游项目代码或发布游戏包。

## 处置原则

来源明确且用途符合条件的资产可进入相应工作包；缺证资产保留原件与历史记录，新增发行先排除或替换。研究参考、生成输入、游戏内素材和宣传素材是不同用途，分别确认。

GPL/LGPL 与 CC 系列的义务按具体许可证、代码组合和分发方式核对，不能用“仅参考”掩盖复制。MIT/Apache 等宽松许可也要保留必要通知，并审查第三方内容。生成服务条款按实际生成日期与账户条件取证，不复制今天的价格页充当历史授权。

历史资产流程曾记载暂缓商务授权调查，本轮用户已明确要求核验；据此恢复调查，保留旧记录。未取得的作者确认、商业条款或授权材料列为 P0-L1 待办，不虚构邮件往来，也不自动对外联系。

阻塞边界：文档和隔离研究可以继续；未明权利阻塞相关代码/资产的新增公开发行。首轮执行见[P0-L1](../milestones/P0/WORK-PACKAGES.md)。
