## 本项目要回答的问题

研究主题：Apple Silicon 端侧推理对照。选明确的模型运行层，记录其依赖和许可，对比相同任务质量下的内存、取消、卸载和游戏渲染竞争。

若双后端维护代价高而收益有限，优先保留一个跨平台后端；不要求 Windows 使用 MLX。
