# 《我有一片田》玩家指南（开发试玩版）

本指南只写当前版本已经能做的事。云同步、官方服务器、PvP、模型对话等未实现能力统一列在文末，不在此处描述。

## 1. 启动与进入农场

1. 打开游戏。第一次启动（还没有 `preferences/settings.json`）会先做几秒的首次性能测试，然后停在画质选择页。
2. 画质可选“低 / 中 / 高”，并显示推荐档位。推荐依据是刚才的实测；没有取得稳定结果时会写明“本次未取得稳定测试结果，先推荐…”。
3. 点“进入农场”。设置保存成功才进入；保存失败会显示“画质已应用，但设置未能保存，请重试。”，此时可点“重试保存并进入农场”，或点“本次使用，不保存”。
4. 加载期间显示“正在读取设置…”“正在加载模型与贴图…”等阶段。资源加载失败会给出原因和“重试加载”。

标题界面（加载页）底部还有“联机：加入朋友的农场，或开一间房”，见第 7 节。

## 2. 照料田地

- 镜头：滚轮缩放；中键拖动转动视角；Shift＋中键平移；点击田块靠近，向后滚轮返回聚焦前的机位。
- 空手点击田格会展开菜单，选择动作。
- 播种：点底部“种植”展开蔬菜横排，选一种拿起种子，再点击土地；可连续点击种植。右键、Esc 或“取消”放下种子。
- 工具：点底部“工具”展开“浇水 / 收获 / 除草 / 开垦”，选中后点击土地连续操作。门前种子篮、锄头、水壶也可直接拿起对应工具。
- 每株作物每轮只能浇水一次，按作物不同增加生长期 12%–30% 的进度；成熟后收获 1 篮。
- 作物按现实时间生长。关闭游戏后再次进入，会从当前时间继续结算，不会回退。
- “建设”用于布置本地院落：选择土地、建筑或摆件，选装饰、点空位，再确认；旋转适用于地面装饰。

农田共 6 块地，每块 16 格；部分边缘格是粗地，需要先“开垦”。另有菜架，只种丝瓜：点击架脚的种植位靠近，再播种；也可点藤蔓或果实浇水、收获。扩架增加位置，缩架前要先收获会被移除的作物。

当前 13 种作物：丝瓜、青菜、白萝卜、菠菜、生菜、茼蒿、香菜、芹菜、雪里蕻、乌塌菜、胡萝卜、小葱、青蒜。生长时间约 30–120 分钟。

## 3. 天气、土壤与灾害

- 天气每 6 小时换一块，一天 4 块。选中田格时，画面上方依次显示天气、土壤和灾害信息。
- 天气行示例：`天气：晴 · 约 3 小时后变化`（晴 / 多云 / 雨）。
- 土壤行示例：`土壤：湿润 · 生长 100%`。天气和灾害会改变土壤湿度，从而影响生长速度。
- 灾害行只在有事件时显示：`灾害：干旱（持续至 …）`，或提前显示 `预警：暴雨 约 N 小时后`。
- 设置 → 世界 → 灾害可选“温和”或“关闭”。默认温和。联机世界中这个开关由世界房主决定，客户端只读。

## 4. 市场

点 HUD 的“市场”。第一次打开会自动开通账户（一次性 120 COIN）并让商人开市；联机世界由成员身份执行，访客只能看。

- 商人报价：青菜、菠菜、白萝卜、胡萝卜、芹菜、青蒜 6 种商品，显示收购价、出售价与可收/可售数量。报价随时间变化。
- 下单：选“买入 / 卖出”、商品、价格（1–1,000,000 COIN）、数量（1–9999）、有效期（1–1,440 分钟，默认 60 分钟）。自己的进行中订单可“撤单”。
- 托管：买入单会冻结现金，卖出单会冻结货物；未成交部分在撤单后解冻，成交时按订单交割。钱包行显示现金、口袋、托管、在途。
- 发货：可在“农田市场”和“港口市场”之间发货，运费 2 COIN，约 10 分钟到达。单人模式到货后点“交付到达货物”；联机世界由世界自动入袋，按钮不显示。
- 订单到期、撮合和到货由世界结算；单人模式在打开市场或执行市场操作时结算，联机模式由权威定时结算。

## 5. 银行

点 HUD 的“银行”。

- 单人模式第一次打开会自动开通银行；联机世界要由成员点一次“开市”。
- 借款期限 7 / 14 / 30 天；本金 10–1000 COIN；费用为本金的 5%（向上取整），到期一次还清本金加费用。
- 面板显示报价、合同列表和“还款”。逾期合同会标为“已逾期”，仍可还款。
- 联机世界访客只能查看，不能开市、借款或还款。

## 6. 宅基（联机世界）

联机农场使用“宅基”面板：

- 6 个固定宅基：甲、乙、丙、丁、戊、己号。
- 可建“小屋”（10 分钟）、“工坊”（20 分钟）、“凉亭”（5 分钟）。当前建造只计时，不消耗材料或现金。
- 宅基下的地块默认无主：第一次在某个宅基建房会自动把该地块记到你名下。每个宅基下方会标出地籍归属——“无主宅基”“这是你的宅基”或“宅基属于 <玩家名>”；别人已经认领的宅基不能建房，面板会禁用建造并说明“这块宅基属于 <玩家名>，不能在别人的地上建房”。
- 施工中可以取消；建成后只有房主能拆。其他成员能看见进度，但不能代拆。

## 7. 联机：开房与加入

入口在加载页的“联机：加入朋友的农场，或开一间房”。

### 加入朋友的农场

1. 向房主要“加入码”。
2. 在面板里填名字（最多 24 个字），粘贴加入码，点“加入”。名字会保存在本机档案里。
3. 等待最多约 20 秒。成功后在同一个加载页继续进入农场。
4. 加入失败会显示具体原因，例如“这串加入码不完整或已损坏，请向房主重新索取。”“连不上这个地址，请确认房主已经启动世界，且在同一网络。”“双方版本不一致，无法进入同一个世界。”
5. 第一次用某个名字进入一个世界时，世界会把这个身份绑定到本机的 `player/player.key`。之后再用同一身份进入，必须带上同一个 key；换电脑或删掉它会被拒绝（见第 9 节与第 10 节）。

### 在这台电脑上开一间房

1. 点“开房并邀请朋友”。游戏会在这台电脑上启动一个无头世界进程，等待最多约 30 秒。
2. 成功后面板显示两串码：**成员加入码**（默认复制到剪贴板）和**访客照料码**。成员码给一起种田的朋友；访客码只能浇水、除草。把码发给朋友，再点“进入这间房”。如果访客码暂不可用，面板会明确提示，成员码与“进入这间房”仍可正常使用；可重启房间再试。
3. 朋友需要在同一局域网。房间端口在 20000–45000 之间随机取空闲值，界面不能指定端口。跨网段、NAT 和公网连接当前未验证。
4. 房主退出游戏时房间随之关闭。想让朋友在你退出后继续种，需要使用常驻服务端（见 `self-host.md`）。

限制与风险：

- 只有带服务器脚本的开发版（编辑器构建）能开房。导出后的游戏点开会提示“这个版本不能在本机开房，需要用带服务器脚本的开发版本运行。”
- 成员加入码包含地址、证书和成员邀请，拿到码的人能以成员身份进入，可以使用市场、银行、建造与收获。访客照料码同样是完整凭证，但只授予浇水、除草，不能收获、播种、建造，也不能使用市场和银行。
- 两串码都可复制；不要把码公开发布。当前没有撤销界面：泄露后需要手动轮换房间数据里的 `invite.bin` 再重开房，两串码会一起失效。
- 联机世界的农场由房间的权威进程保存，客户端不写本地农场存档。

## 8. 邻居与权限

联机世界 HUD 显示“邻里”和“宅基”，不显示本地“建设”和“菜篮”。

“邻里”面板包含：在线成员、邀请、联系人、留言、照料授权，以及“允许邻居偷一份成熟收成”、送一份收成、留一句话。

- 成员（加入码默认角色）可以种植、收获、浇水、除草、开垦、开关偷菜、建造/拆除，并使用市场与银行。
- 访客只能浇水、除草；市场与银行面板显示只读，经济操作提示“访客只能查看市场和银行，不能下单、发货、开市或借贷。”宅基面板对访客显示为只读：按钮不可用，并说明“访客只能查看宅基，不能建造或拆除。”房主开房成功后，联机面板会同时显示成员加入码和“访客照料码”，两种朋友各用各的码。
- 偷菜默认关闭。开启后别人可以收走你成熟的作物：每个主人每天最多 3 份，同一人 10 分钟内只能取一次；未开启时提示“这是别人种的，对方没有开放偷菜”。
- 送收成固定 1 份，只能送给联系人。“允许收获”授权也只对联系人可用。
- 留言可发给“公开”或联系人，最多 200 字。
- 想和同在一间房里的人成为邻里：在“在线成员”里点对方一行的“邀请为邻里”。对方在“邀请”区选择“接受”或“拒绝”；只有联系人才能互相留言、送礼和授权收获。已经是你联系人、已有待答邀请或就是你自己的人不会显示这个按钮。
- 联机世界中院落布局由世界房主维护；本地编辑会提示“联机模式下，院落由世界房主维护。”
- “组织”面板显示本世界的组织、成员与职位，并提供创建、加入、退出、任命和交接。成员能做什么由权威判定；界面只显示权威返回的结果，不本地改写职位。
- “单位”面板显示权威名册（所有者、兵种、人数、装备、驻地、欠供天数）。成员可以招募、解散自己的单位（需确认）并触发补给；招募从自己的现金和粮草扣除，补给按各所有者口袋里的粮草结算。访客只能查看；单机打开会提示“单位需要进入共享世界。”。单位目前只存在于共享世界，尚未参与战斗或行军。
- “基金”面板显示各公共基金的负责组织、负责人、余额、累计支出与各成员缴入。组织成员可以开立基金并缴入自己的现金；负责人（keeper）在组织仍允许其支出时才能支出，支出从基金转入世界的公共账户；换届需二次确认，新负责人必须是组织成员。所有权限与余额由权威判定，面板只显示权威结果；单机打开会提示“公共基金需要进入共享世界。”。
- “公建”面板显示本世界的公共项目（村口广场、公井、石板路）：类型、承诺额与是否足额、状态和建成时间。成员可以登记项目、承诺或退回承诺，并指定一支公共基金在足额后建成；承诺不是立即付款，建成时基金才真实支出固定成本。项目登记时可用下拉选择世界地籍里的地块 id，也可手输（如 `parcel_01`）；建成后会在对应宅基位置显示简易石盘/井台/石板标记，未绑定地块的项目只显示在面板中。权限与余额由权威判定，拒绝原因原样显示；单机打开会提示“公共项目需要进入共享世界。”。
- “交战”面板显示当前制度下的目标损失预算与近期交战结果。成员填写防守者、双方参战单位、位置与可选地块后可发起一次交战，界面会先要求确认；同意状态、单位归属、损失上限与资产结算都由权威判定，拒绝原因原样显示。界面不显示未由权威返回的战报明细；单机打开会提示“交战需要进入共享世界。”。
- “参战”面板显示当前参与制度、房主、风险区域、时间窗口、参与者与损失累计。房主可以声明和平或有限冲突（固定格式填写区域与窗口）；其他成员可以同意作为进攻方或防守方参与，或申请退战（延迟生效，带确认框）。界面不自行放行或拦截，权威拒绝的原因会原样显示；单机打开会提示“参与制度需要进入共享世界。”。
- “纠纷”面板显示权威下发的案件、公开状态与审计记录。成员可以立案（引用权威事件编号）、提交证据、申诉；权威花名册中的管理员可以受理、驳回、裁定、更正和结案，裁定/更正/结案前需确认。面板只转发请求，角色、案件状态与裁定语义都由权威判定；单机打开会提示“纠纷需要进入共享世界。”。当前裁定中的“补偿”只是记录，不会自动转移资产。

断线时画面停在最后一次确认的状态，客户端按 1/2/4/8/16/30 秒退避重连，并提示“正在重新连接世界（第 N 次）…”或“已重新连上世界”。重连期间仍可点击，但不会产生本地写入。

## 9. 设置与存档

设置面板标签页：显示、音量、操作、关于、（开发者）、世界。

- 显示：画质预设、分辨率、FSR 超分、场景细节、阴影、光照、抗锯齿、景深、窗口模式、轻微晃动及空闲秒数。
- 音量：总音量、音乐、音效。
- 操作：完整操作说明。
- 世界：灾害开关、“导出世界”“导入世界”“重置身份”。
- 开发者页在正式构建中默认隐藏。

“导出世界”选择一个空文件夹，生成世界包（`worlds/<世界ID>/world.json`，格式 3，规则 27）。文件夹非空会提示“这个文件夹已有内容，请选择一个空文件夹。”“导入世界”选择包含 `world.json` 的目录，确认“导入这个世界包？”后点“导入并替换”。导入前会把现有存档备份到 `import-backups/world-<ID>/`；目标目录原本没有存档时没有这个回滚点。联机世界中不能导入本地存档。

存档位置：

| 系统 | 目录 |
|---|---|
| macOS | `~/Library/Application Support/Godot/app_userdata/我有一片田/` |
| Windows | `%APPDATA%\Godot\app_userdata\我有一片田\` |

| 内容 | 路径 |
|---|---|
| 本地农场（v27） | `farm-v27/farm.json`、`farm.backup.json`、`farm.pending.json` 等 |
| 天气记录 | `farm-v27/nature.json` 及其备份 |
| 相册 | `farm-v27/album/` |
| 界面设置 | `preferences/settings.json` |
| 本机玩家身份与名字 | `player/player.json`；身份凭据 `player/player.key`（与 ID 一起备份，缺一不可） |
| 开房数据 | `rooms/world/`（含 `farm.json`、`invite.bin`、`world.key`、`server.crt`） |

保存时机：窗口失去焦点、正常退出、市场/银行等结算后。退出时保存失败会显示“保存未完成，最新进度仍在本次窗口中。请重试保存。”，按钮为“重试保存”和“仍然退出（最新进度未保存）”。

保存失败后，内存里的进度已经领先于磁盘。此时市场下单/撤单/发货/交付与银行开市/借款/还款会直接显示“保存失败，暂时不能进行经济操作。请先重试保存。”，不会继续提交新命令；任意一次保存成功后自动恢复。断线时未完成的请求会被取消并在对应面板说明，重连后需要重新提交。

## 10. 常见故障

| 现象 | 处理 |
|---|---|
| 存档无法读取，但存在可用备份 | 面板显示“存档未能读取，可恢复上一份备份。最近的改动可能丢失，原文件会保留。”点“从备份恢复”。损坏原文会保留为 `farm.unreadable.<pid>.<时间>.json`。不会自动回滚。 |
| 存档与备份都无法读取 | 显示“存档与备份都无法读取。原文件已保留，修复文件后可重试。”先备份整个 `farm-v27` 目录，再点“重试读取”。 |
| 存档来自其他版本 | 显示“这份存档来自其他版本。请使用对应版本打开，原文件已保留。”不要手改版本号。 |
| 天气记录来自更新版本 | 显示“天气记录来自更新的版本，请先更新游戏。原文件已保留。” |
| 天气记录损坏 | 显示“天气记录无法读取，原文件已保留。修复后可重试。” |
| 加入时提示“这个世界登记的是另一个玩家档案” | 本机 `player/player.key` 不是这个世界最初绑定的那一份（常见于换电脑、恢复旧备份或用错档案）。先恢复原 `player.key` 再试；确实找不回时，请房主删除世界目录 `player_bindings.json` 中这个 ID 的条目后重新加入。 |
| 加入时提示“本机的玩家凭据缺失或损坏” | `player/player.key` 缺失或不是 44 个字符的 base64。游戏不会自动换新凭据；从备份恢复该文件，或确认要放弃这个身份后再处理。 |
| 想换一个玩家身份 | 设置 → 世界 → “重置身份”，确认后生成新的玩家 ID 与本机凭据。旧 `player.json`/`player.key` 会归档为 `player.identity_reset.*` 保留，但它在各世界里的成员资格和开户赠款不会迁移；重启游戏或重新进入世界后生效。失败时旧文件保持不变。 |
| 保存失败 | 按第 9 节的重试/退出选项处理；退出前先备份整个存档目录。保存失败期间经济操作会被暂时拒绝。 |
| 没有网络 | 单人游戏不需要网络，可以完整游玩。只有加入/开房需要局域网和 WSS 连接。 |
| 加入时报“双方版本不一致” | 双方必须使用同一规则/协议版本（当前规则 27、协议 1）。 |
| 开房提示不支持 | 导出构建不能开房，改用编辑器构建或常驻服务端。 |
| 操作被拒“世界正在搬迁，暂时不能操作” | 服务端处于只读退役状态，等房主恢复写入。 |
| 操作被拒“地里已经变了，请再试一次” | 世界状态已变化，重试该操作。 |

## 11. 尚未提供

以下能力在当前实现中不存在，本指南不提供操作步骤：

- 云同步、跨设备存档同步、官方公共服务器。
- 全面 PvP、即时战斗操作与战后战报动画（当前的有限冲突由“参战 / 交战”面板按参与制度发起，属于规则层交战）。
- 模型对话（本地或云端 AI 对话）。
- 加入码撤销界面、二维码。
- 自定义房间名、端口或房间存档位置；NAT/跨网段联机。
- 导出构建作为服务端、Linux 实机支持、Windows 实机开房验证。
- 邀请有效期、一次性邀请、按命令的细粒度权限矩阵。
- 存档格式自动迁移（当前只接受 v27；2.0 格式变更前需先做恢复演练）。
- 代码签名、公证与正式发行。
