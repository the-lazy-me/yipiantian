# 世界系统总纲

状态：2.0 目标设计；除[基线](research/BASELINE.md)明确列出的能力外，均未因本文而实现。产品裁决依据[世界宪章](01-VISION.md)。

## 世界的三个尺度

家园承载种植、照料、烹饪、造屋和观看；村落承载互访、集市、公共设施与邻居关系；区域承载物流、土地组织、气候差异和可选政治冲突。镜头拉远不必提高模拟精度，进入细节也不改变权威资源数量。

基础生活循环是观察环境、作出自愿选择、投入材料或时间、获得世界反馈、留下变化。农业产出可自用、赠送、储存或交易；交易提供建设与组织协作的资源；治理与执法保障共同生活。没有要求玩家沿这一顺序解锁全部系统。

## 系统职责与连接

| 系统 | 持有的事实 | 主要输入与输出 | 详细规格 / 阶段 |
|---|---|---|---|
| 农耕 | 地块、作物批次、生长与库存 | 时间、水土条件、照料→收成 | [自然](systems/nature.md)，M0/M6 |
| 生态气象灾害 | 区域天气、土壤环境、风险事件 | 种子与气候规则→生产条件、预警 | [自然](systems/nature.md)，M6 |
| 动态市场 | 订单、报价、库存预留、成交 | 供需、运输、消耗→价格与交付 | [经济](systems/economy-finance.md)，M7 |
| 银行金融 | 账本、债权、准备金、保险合同 | 已确认交易、风险→融资与偿付 | [经济](systems/economy-finance.md)，M8 |
| 社交与自建房 | 联系关系、许可、房间成员 | 邀请、访问、互助→社会经历 | [社会](systems/society-housing.md)，M4/M5 |
| 自建房屋 | 蓝图、占地、材料与使用权 | 建设命令→可居住、可装饰空间 | [社会](systems/society-housing.md)，M5/M11 |
| 领土与政治 | 地籍、组织、规则版本 | 合法取得、议事→权利与公共支出 | [治理](systems/politics-conflict-law.md)，M11 |
| 私兵与有限 PvP | 单位、补给、冲突范围 | 招募、授权与风险同意→有限损失 | [治理](systems/politics-conflict-law.md)，M12 |
| 官府执法 | 案件、证据、裁决与执行 | 规则事件、申诉→处罚与恢复 | [治理](systems/politics-conflict-law.md)，M11/M12 |
| NPC/商人 | 人格、私有记忆、意图 | 可见事实→经校验的行动建议 | [AI](06-AI-SYSTEM.md)，M9/M10 |

“自建房”包含两种能力：玩家自托管房间与游戏内建设住宅。前者管服务器和成员，后者管土地、材料、空间；两者不共用权限名或状态对象。

## 跨系统因果样例

干旱降低某区有效生长速度，库存减少后商人的采购意愿提高；市场报价由有限预算和库存生成，价格变化使其他地区有动力运来货物。运输消耗成本并承担事先声明的风险；保险只赔付已登记的受保损失。官府可公开采购修渠，但玩家可以继续经营未受影响的作物，不被要求接“救灾主线”。

每个环节先形成权威事件，再影响下游。天气显示动画不能扣产量，商人对话不能完成转账，官员评价不能直接改变地契。下游消费同一事件时使用唯一编号，重试不再扣款或赔付。

## 规则配置与世界类型

默认世界采用温和农业、和平制度、有限离线结算和关闭云端 AI。熟人房可开启有限偷菜、贸易和公共建设；有限冲突房进一步定义风险区域、同意方式、损失上限、时间窗口和退出规则。房间设置成为版本化世界规则，并在加入前呈现主要差异。

规则升级采用预告与生效时间；涉及既有合同和财产时沿用合同签订版本，或由参与人明确接受转换。管理者可恢复备份、封禁恶意成员，但这种管理行为要留下记录，不能冒充世界自然演化。

## 节奏与数值设计

现实昼夜、农业逻辑时间、季节与社会结算分别命名。现有 UTC 生长语义先保留；季节和经济结算的时间比例在 M6/M7 实验后固定。数量、价差、贷款期限、灾害频率均为实验变量，不能从历史演示数值自动扩展成 2.0 标准。

机制实验至少覆盖普通生活者、专注经营者、长时间离开者和尝试套利者。评价维度为选择多样性、解释性、恢复成本和系统稳定性；不以在线时长或完成任务数作为唯一成功指标。
