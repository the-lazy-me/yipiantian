## 测试层级与样本

纯规则测试验证时间、资源和权限；持久化集成验证事务与恢复；双端验证协议、重连与迁移；真实场景验证输入、视觉、声音与性能。相同风险不在每层机械复制，跨边界的问题必须在对应边界出现时验证。

首批样本包含最小空世界、普通混种院落、已有 v27 内容、长离线世界、两名玩家同时操作和损坏导出包。后续增加有债务、有在途货物、有争议土地的世界，固定种子和版本。真实玩家数据仅在获得授权并脱敏后用于夹具。

## 能效测量

在相同硬件、电源方案、分辨率、相机、画质、场景、前后台状态与冷暖缓存条件下对比。分别报告进程 CPU、GPU 时间/占用、工作集、引擎纹理与缓冲、唤醒频率和整机增量功率；这些量不可互相替代。测量工具自身开销须说明。

P0 先确定 Windows 代表机、Mac mini M4/M4 Pro 的可用设备和基线；没有设备即写缺测。目标预算以实测结果和体验取舍建立，不引用 RTX4090 的历史短测证明 Mac 或核显达标。短测、长时、休眠恢复与温度稳定分别得出结论。

初始执行方案为每模式稳定后做三组配对样本，再做一次连续八小时驻留及多次休眠恢复；这是未来验收计划，未在本次执行。样本失焦、遮挡或有外部负载时按实际目的分类，不冒充前台性能。达到判定证据后停止重复测量。

## 经济与社会模拟

M3 建立无图形世界实验入口，后续使用同一规则实现推进 M6–M12 场景。模拟从小人口正常交易开始，再加入歉收、囤积、坏账、组织退出和冲突。验证资源不变量与恢复路径；统计集中度、价格波动、破产比例和恢复时间用于调参，不预先把某个数值宣称为公平。

长时间加速模拟不能代替真实长期驻留，也不能证明真人策略穷尽。每次报告注明模拟世界数、逻辑时长、种子集合、规则版本及实际运行时间。

## 发布与停止条件

数据丢失、重复资金、越权资产转移、无法关闭的资源占用、未明授权资产进入发行包均阻塞对应发布。可接受的视觉小差异记录在已知问题中，但不能将断裂模型或不可读 UI 归为平台正常差异。

发布候选必须对应固定提交，干净检出 LFS、使用锁定引擎与模板、审计资源、生成摘要并在目标机器安装启动。正式公开发布前核验 Windows/macOS 签名、权限提示、卸载、升级和回退。缺少一种平台实机证据时只陈述已验证平台。

所有阶段的证据位置在各自 PLAN 中指定；当前真实调查与文档检查见[基线](research/BASELINE.md)，原型状态见[可行性登记](feasibility/P0-FEASIBILITY.md)。
