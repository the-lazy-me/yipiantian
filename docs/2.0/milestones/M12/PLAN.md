# M12 · 私兵、战略与有限 PvP

状态：计划中，未验收。前置：M11 地籍/执法；M7 物流；M8 风险合同。

## 阶段成果

开放有成本、有边界、可以不参与的战略竞争。

权威规格：[相关设计](../../systems/politics-conflict-law.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M12-01 · 实现单位和补给

实施：有限护卫/民兵、装备、驻地、工资与粮草，先低频战略结算。

交付与验收：无资源不能无限招募，欠供有明确能力变化。

### M12-02 · 落实参与制度

实施：和平/有限冲突、区域、窗口、同意、退战延迟、离线保护与损失上限。

交付与验收：同一攻击在和平房拒绝；房主不能静默扩大风险。
实现记录（纯规则切片，不表示 M12-02 完成）：[RECORD-02 · 参与制度](RECORD-02-participation.md)，裁决 [ADR-025](../../decisions/ADR-025-conflict-participation.md)。尚未接入网络、存档、资产扣除与战利品。

### M12-03 · 实现交战与转移

实施：校验命令、冻结资源、结算唯一结果、扣除损失并发放真实战利品。

交付与验收：重试不重复战利品，反复袭击不能突破同目标上限。
实现记录（纯规则切片，不表示 M12-03 完成）：[RECORD-03 · 交战与转移](RECORD-03-settlement.md)。尚未接入网络、农场存档、真实资产账本与 UI。

### M12-04 · 完成执法闭环

实施：调查、证据、裁定、执行、申诉与补偿，区分游戏官府与服务器管理。

交付与验收：恶意举报不直接定罪，错判可更正且审计保留。

### M12-05 · 验证不参战体验

实施：普通农户、商队、弱小组织与攻击者场景，观察恢复成本和骚扰路径。

交付与验收：和平生活完整，保护区和基础住所不受越权转移。

## 集成验收

Q7/Q9；有限损失与资产守恒是硬门槛，玩法满意度另需体验。

## 回退与边界

停止新冲突，结清已确认单次交战；保留和平生活与追溯，不回滚整村掩盖争议。

不引入无上限掠夺、强制参战或默认大型实时战争。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
