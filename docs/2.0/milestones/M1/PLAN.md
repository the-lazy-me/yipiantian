# M1 · Windows/macOS 窗口版与迁移

状态：计划中，未验收。前置：M0 数据契约和规则等价。

## 阶段成果

交付可实际游玩的双平台窗口版，完成个人世界双向迁移。

权威规格：[相关设计](../../05-DATA-AND-NETWORK.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M1-01 · 建立构建矩阵

实施：核对锁定引擎与导出模板、目标架构、渲染后端和最低系统版本；新增 macOS 导出配置与独立构建任务。

交付与验收：产物标明提交、平台、架构和模板版本；现有 Windows 发布入口仍可使用。

### M1-02 · 适配文件与输入

实施：检查中文路径、用户数据目录、大小写、权限、键鼠、窗口缩放与高 DPI；避免依赖 Win32 宿主才能启动。

交付与验收：两平台均可播种、保存、关闭、重开和建设预览；失败有可理解提示。

### M1-03 · 交付导入导出界面

实施：实现包摘要、范围说明、隔离验证、旧世界保留与恢复入口。

交付与验收：Windows 创建→Mac 修改→Windows 继续，库存、布局和身份逐项一致。

### M1-04 · 验证安装与签名流程

实施：核验 Apple 当前签名/公证要求和 Windows 包行为；没有签名条件时如实区分开发包与公开发行包。

交付与验收：干净设备启动与升级记录齐备；不可用权限有明确回退。

## 集成验收

Q2/Q3；验证未知版本、只读目录、导入中断、显示缩放及正常退出。

## 回退与边界

保留上一版本程序和匹配快照，升级失败不覆盖旧数据；回退不读取更高 schema。

桌面嵌入在 M2；不因此承诺全部 Mac/Windows 版本。
