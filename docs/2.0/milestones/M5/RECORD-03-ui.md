# M5-01 · 邻里面板（切片）

执行日期：2026-11-15。状态：联机社交界面切片完成，不表示 M5 或 M5-01 验收完成；只覆盖已在线玩家。前置：[M5-01 社交关系模型](RECORD-01-social.md)、[M4-06 客户端入世](../M4/RECORD-06-client.md)。

## 实现

此前的社交规则、RPC 与授权都只有数据层，玩家看不到联系人、留言与授权。本切片把这些对象摆到界面上，并把点击变成对权威的请求。

- `Game/ui/social_panel.gd`：一个只负责呈现的面板。
  - `present(view, roster)` 接收整份社交视图与在线名册，重建五个分区：在线、邀请、联系人、留言、照料授权；视图为空时显示“还没有收到世界的社交信息”，而不是假装没有人。
  - 面板不判断任何规则：接受/拒绝邀请、移除/屏蔽联系人、已读/删除留言、撤销授权都只发出 `action_requested(action, args)`；能不能做由权威回答。
  - 发送区由一行输入和一个目标下拉组成（公开或某个联系人）；空白文本在本地拦下并提示，不发出请求。
  - 名册里没有显示名的成员显示为“一位匿名旅人”，不编造名字。
  - 授权行显示命令、范围（整座农场或几块地）与是否限时；只有自己发出的授权才有“撤销”。
- `Game/scenes/farm_hud.gd`：联机模式下的“邻里”入口（按项目现状用文字按钮，不借用已有图标）；同时隐藏“建设”和“菜篮”，因为这两个功能当前只存在于本地存档。
- `Game/scenes/main.gd`：只在联机模式创建面板，打开时请求 `state`，收到权威事件后刷新；权威拒绝时把原因显示在面板顶部（复用同一套中文文案）。

```sh
perl -e 'alarm shift; exec @ARGV' 120 "$GODOT" --headless --path Game \

```

## 未覆盖

- 只在联机模式出现；单机模式没有“写信给 NPC”之类的替代入口。
- 没有自定义授权：界面只能发“收获、整座农场、不过期”，命令种类、地块选择与到期时间仍只能通过 RPC 参数表达。
- 没有未读数、角标或通知；新留言只在面板打开时刷新（收到推送会刷新一次并提示“留了话”）。
- 没有屏蔽列表的展示与解除入口，也不显示被谁屏蔽；只能从联系人行发起屏蔽。
- 邀请需要对方 Player ID，界面没有“按名字找人”或分享入口；ID 仍需在界面外交换。
- 没有时间戳、分页或长列表虚拟化；留言上限 256 条、联系人 128 条没有做过界面压力测试。
- 没有键盘导航、读屏或文本缩放的专项验证；面板沿用现有字体与配色。
- 面板关闭后不清空视图，下一次打开先显示旧内容直到权威回复。
