# M11 · 领土、组织与地方治理

状态：计划中，未验收。前置：M5 建设权限；M8 公共账本；M10 的官员表现可后接。

## 阶段成果

让地籍、公共资源与组织治理形成可审计的社会规则。

权威规格：[相关设计](../../systems/politics-conflict-law.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M11-01 · 建立地籍

实施：区域边界、权利人、用途、通行权与有限租赁，连接住宅蓝图。

交付与验收：购买/交换不会双重归属或封死唯一公共通路。

实现记录（切片，不表示 M11-01 完成）：[RECORD-01 · 地籍规则](RECORD-01-cadastre.md)、[RECORD-02 · 接入世界权威](RECORD-02-cadastre-authority.md)（独立 `territory.json`、连接身份命令、重启幂等）、[RECORD-03 · 地籍可见性与宅基面板](RECORD-03-cadastre-visibility.md)（摘要携带公开归属、面板显示无主/本人/他人）、[RECORD-06 · 地籍客户端主张/释放](RECORD-06-cadastre-client.md)（RPC 9/10、面板动作按钮、权威裁决后广播摘要）。建造门禁见 [ADR-028](../../decisions/ADR-028-build-land-authority.md)；转让入口与通行判定仍未接。

### M11-02 · 建立组织

实施：成员、职位、权限、公共账户与交接，先合作社和商会。

交付与验收：换届/退出不改变组织资产身份，越权支出拒绝。

实现记录（不表示 M11-02 完成）：[RECORD-04 · 组织规则](RECORD-04-organizations.md)（纯规则：成员、职位、交接与权限表）；[RECORD-08 · 组织权威接入](RECORD-08-organization-authority.md)（RPC 11/12、`organizations.json` 持久化、连接身份授权、重启保留）；[RECORD-09 · 组织治理界面](RECORD-09-governance-panel.md)（组织列表、创建/加入/退出/任命/交接意图，只显示权威视图）。尚无真实公共账户与基金支出。

### M11-03 · 实现规则决议

实施：提案、表决或授权、预告、生效、版本和撤销，先公共建设与税费。

交付与验收：既有合同不被追溯改写，成员能查看规则差异。
实现记录（纯规则切片，不表示 M11-03 完成）：[RECORD-05 · 规则决议](RECORD-05-resolutions.md)。提案、投票、预告、生效、撤案与撤销均有确定性窗口与版本；撤销只缩短有效期，不重写历史。未接权威、网络、存档或界面。

### M11-04 · 建立案件基础

实施：用权威事件登记纠纷，明确受理、证据、权限、申诉与更正。

交付与验收：AI 建议不能直接处罚，管理员操作单独审计。

## 集成验收

Q6/Q7/Q9；覆盖双地契、组织解散、负责人离线与公共资金争议。

## 回退与边界

冻结新地籍操作，按更正事件修复错误；保留历史权属和决议版本。

复杂世袭、多级国家和人口政治仅候选；不要求玩家加入组织。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
