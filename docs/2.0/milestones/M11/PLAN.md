# M11 · 领土、组织与地方治理

状态：实现中（已有切片记录），未验收。前置：M5 建设权限；M8 公共账本；M10 的官员表现可后接。

## 阶段成果

让地籍、公共资源与组织治理形成可审计的社会规则。

权威规格：[相关设计](../../systems/politics-conflict-law.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M11-01 · 建立地籍

实施：区域边界、权利人、用途、通行权与有限租赁，连接住宅蓝图。

交付与验收：购买/交换不会双重归属或封死唯一公共通路。

实现记录（切片，不表示 M11-01 完成）：[RECORD-01 · 地籍规则](RECORD-01-cadastre.md)、[RECORD-02 · 接入世界权威](RECORD-02-cadastre-authority.md)（独立 `territory.json`、连接身份命令、重启幂等）、[RECORD-03 · 地籍可见性与宅基面板](RECORD-03-cadastre-visibility.md)（摘要携带公开归属、面板显示无主/本人/他人）、[RECORD-06 · 地籍客户端主张/释放](RECORD-06-cadastre-client.md)（RPC 9/10、面板动作按钮、权威裁决后广播摘要）。建造门禁见 [ADR-028](../../decisions/ADR-028-build-land-authority.md)；转让入口与通行判定见 [RECORD-10 · 地籍转让与通行判定](RECORD-10-territory-transfer.md)（2026-11-16，切片完成，未验收；转让接收人必须是已开户成员 `unknown_member`，新增只读 `can_pass` 权威动作，已建成且绑定地块的公共项目对其地块放行通行，但通行不授予建造权；无定价/托管/租赁、无连通性寻路、无转让选人 UI）。连通性只读权威动作：[RECORD-18 · 地籍连通性接入世界权威](RECORD-18-territory-blocking-authority.md)（2026-11-16，切片完成，未验收；公共入口取已建成 `village_square`，宅基名单取农场已建成建筑经 ADR-028 序号映射，`territory` 通道新增只读动作 `blocking`，成员/访客/匿名可读且不写任何文档；**写入门禁增补（2026-11-16）**：`claim_territory` 与 BUILD 的自动主张在写盘前用同一路由判定，会切断公共入口到宅基唯一通路时返回 `blocks_public_path` 且不写任何文档，无入口时放行以免新世界自锁，`transfer`/`release` 不改变匿名可通行性不设门禁，重放不经过门禁；多入口、住宅与工坊区分、界面与 Windows 未覆盖）。

### M11-02 · 建立组织

实施：成员、职位、权限、公共账户与交接，先合作社和商会。

交付与验收：换届/退出不改变组织资产身份，越权支出拒绝。

实现记录（不表示 M11-02 完成）：[RECORD-04 · 组织规则](RECORD-04-organizations.md)（纯规则：成员、职位、交接与权限表）；[RECORD-08 · 组织权威接入](RECORD-08-organization-authority.md)（RPC 11/12、`organizations.json` 持久化、连接身份授权、重启保留）；[RECORD-09 · 组织治理界面](RECORD-09-governance-panel.md)（组织列表、创建/加入/退出/任命/交接意图，只显示权威视图）。尚无真实公共账户与基金支出。

解散与资产清算纯规则切片：[RECORD-17 · 组织解散与资产清算](RECORD-17-organization-dissolve.md)（2026-11-16，切片完成，未验收；`status` 增加 `closed`，负责人可解散但要求无在途支出，关闭保留成员与历史行，清算只返回按缴入比例的确定性退款意图与总额守恒，成功命令按摘要重放；未接权威/网络/界面，不移动任何钱）。权威接线：[RECORD-20 · 组织解散接入世界权威](RECORD-20-organization-dissolve-authority.md)（2026-11-16，切片完成，未验收；负责人经 `execute_organization("dissolve")` 真正退款并关闭组织，退款分录 id 由组织/命令/缴入者派生，组织或基金文档任一写失败都可凭分录或存档记录重试且不二次付款，基金行在关闭后移除；视图新增 `status`/`closed_utc`（摘要块同步），网络答复转发 `clearing`，治理面板新增带二次确认的解散入口并把退款总额回显；真实共享世界的面板端到端与 Windows 未覆盖）。退款半提交恢复增补（2026-11-16）：启动校验只额外接受「基金行余额大于已清零账户、且每笔退款都有账本 `org_refund_` 付款分录」的该行半提交，其它偏差仍拒绝启动；容忍下沉到基金不变式，其他组织不再被待恢复行整体阻塞；加载时直接补完「组织已关闭 + 清算记录 + 基金行仍在 + 账户现金 0」的残留（不转账、不需负责人在线、不依赖有界账本，且先于总校验执行，分录被淘汰也不影响；只读世界只在内存补完不写盘），组织仍活跃时恢复不要求原命令 id、由历史负责人用新 id 补完；删除基金行前要求账户现金为 0；已关闭组织拒绝新基金与缴入（`org_closed`）；补完命令同 id 重放为 `duplicate`。`ORGANIZATION_AUTHORITY_TEST` 增至 200 项；账本 512 条淘汰后在“组织仍活跃”窗口的证据丢失仍未覆盖。

### M11-03 · 实现规则决议

实施：提案、表决或授权、预告、生效、版本和撤销，先公共建设与税费。

交付与验收：既有合同不被追溯改写，成员能查看规则差异。
实现记录（纯规则切片，不表示 M11-03 完成）：[RECORD-05 · 规则决议](RECORD-05-resolutions.md)。提案、投票、预告、生效、撤案与撤销均有确定性窗口与版本；撤销只缩短有效期，不重写历史。持久化切片：[RECORD-11 · 规则决议 sidecar](RECORD-11-resolutions-store.md)（2026-11-16，切片完成，未验收；`resolutions.json` 严格四键信封、64 KiB、有界重放日志、缺失不写盘、pending+回读+rename 原子替换，异世界/损坏/超限拒绝启动，`ResolutionState.normalize()` 恢复 JSON 整数形状）。仍未接权威、网络、摘要或界面。权威与网络接线：[RECORD-12 · 规则决议权威与 RPC](RECORD-12-resolutions-authority.md)（2026-11-16，切片完成，未验收；打开世界加载 sidecar，`execute_resolution()` 在副本上执行并在同一次原子保存中写入候选与命令日志，RPC 27/28、48 KiB 预算与命令令牌桶，视图按公开/成员/相关成员三级隐私分级；无摘要推送、表决资格不读组织职位）。界面：[RECORD-13 · 规则决议面板](RECORD-13-resolutions-panel.md)（2026-11-16，切片完成，未验收；底栏「决议」入口，版本差异、决议行、成员/相关成员/访客三级渲染、提案表单、表决与生命周期二次确认、权威拒绝文案，只转发意图；无真实网络 UI 联调与真实点按；同批修好底栏 16 个入口在 1600 逻辑宽度下溢出）。效果纯规则：[RECORD-14 · 规则决议效果](RECORD-14-resolution-effects.md)（2026-11-16，切片完成，未验收；税费只对给定未来收入计算、公共建设两个固定系数、应用水位保证同一版本只生效一次）。效果接入权威与持久化：[RECORD-16 · 决议效果权威](RECORD-16-resolution-effects-authority.md)（2026-11-16，切片完成，未验收；`resolution_effects.json` 严格三键信封、64 KiB、缺失不写盘，激活成功后登记效果并在打开世界时按生效版本幂等补齐，撤销只让查询归零不改效果字节，损坏/异世界/与决议不一致拒绝启动，视图顶层新增只读 `effects`；跨文件仍分两次原子替换，无 UI、摘要或真实收入结算）。
