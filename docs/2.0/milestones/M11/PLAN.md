# M11 · 领土、组织与地方治理

状态：计划中，未验收。前置：M5 建设权限；M8 公共账本；M10 的官员表现可后接。

## 阶段成果

让地籍、公共资源与组织治理形成可审计的社会规则。

权威规格：[相关设计](../../systems/politics-conflict-law.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M11-01 · 建立地籍

实施：区域边界、权利人、用途、通行权与有限租赁，连接住宅蓝图。

交付与验收：购买/交换不会双重归属或封死唯一公共通路。

### M11-02 · 建立组织

实施：成员、职位、权限、公共账户与交接，先合作社和商会。

交付与验收：换届/退出不改变组织资产身份，越权支出拒绝。

### M11-03 · 实现规则决议

实施：提案、表决或授权、预告、生效、版本和撤销，先公共建设与税费。

交付与验收：既有合同不被追溯改写，成员能查看规则差异。

### M11-04 · 建立案件基础

实施：用权威事件登记纠纷，明确受理、证据、权限、申诉与更正。

交付与验收：AI 建议不能直接处罚，管理员操作单独审计。

## 集成验收

Q6/Q7/Q9；覆盖双地契、组织解散、负责人离线与公共资金争议。

## 回退与边界

冻结新地籍操作，按更正事件修复错误；保留历史权属和决议版本。

复杂世袭、多级国家和人口政治仅候选；不要求玩家加入组织。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
