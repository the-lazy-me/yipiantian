# M6 · 生态气象与灾害

状态：计划中，未验收。前置：M3 时间与事件；M5 的生活保护基线。

## 阶段成果

自然条件影响生产，同时保持离线可恢复与温和生活。

权威规格：[相关设计](../../systems/nature.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M6-01 · 固定自然时间语义

实施：区分现实昼夜、农业时间与季节，建立天气事件与存储。

交付与验收：读档不重抽天气，同一事件在各模式一致。

记录：[RECORD-01-nature-time](RECORD-01-nature-time.md)（2026-11-15，切片完成；单机场景接入与世界包迁移未覆盖）。

### M6-02 · 接入有限环境变量

实施：先做区域降雨和地块湿度，再用实验决定温度/肥力是否进入。

交付与验收：玩家可解释生长变化；在线与离线同输入结果一致。

记录：[RECORD-02-rain-moisture](RECORD-02-rain-moisture.md)（2026-11-15，切片完成，未验收；单机已接入自然种子、天气结算与湿度／倍率提示，温度、肥力、排水与灾害未覆盖）。

### M6-03 · 实现灾害与恢复

实施：为干旱/暴雨等代表事件建立预警、影响范围、保护与恢复路径。

交付与验收：温和模式不毁基本生活，风险模式损失受规则上限约束。

记录：[RECORD-03-disasters](RECORD-03-disasters.md)（2026-11-15，切片完成，未验收；温和模式区域级干旱／暴雨、种子推导与预警视图；风险模式、按地块范围与灾害表现未覆盖）。

### M6-04 · 联动表现和居民规则

实施：天气影响可见氛围与规则 NPC 作息，真实天气仅作可选输入。

交付与验收：断网可继续；停用灾害后普通种收完整。

记录：[RECORD-04-weather-presentation](RECORD-04-weather-presentation.md)（2026-11-15，天气表现切片完成，未验收；当前天气的程序化降雨与阴／雨光照、HUD 天气行；灾害表现、声音与真实天气适配未覆盖）。居民作息部分切片见 [RECORD-05-resident-routines](RECORD-05-resident-routines.md)（2026-11-15，未验收；雨天在各自现有导航空间内避雨并停留，跨空间上岸仍被导航不连通阻断）。灾害可见性切片见 [RECORD-07-disaster-presentation](RECORD-07-disaster-presentation.md)（2026-11-15，未验收；HUD 灾害／预警一行与可逆的场景提示；风险模式、实机画面与共享世界可控灾害夹具未覆盖）。
