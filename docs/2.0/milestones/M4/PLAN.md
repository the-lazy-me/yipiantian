# M4 · 局域网、自建房与跨平台联机

状态：计划中，未验收。前置：M1 双平台客户端；M3 权威服务。

## 阶段成果

Windows/Mac 玩家进入同一世界，并能迁移服务器而保留身份。

权威规格：[相关设计](../../05-DATA-AND-NETWORK.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M4-01 · 选择传输与身份方案

实施：对比 Godot 原生网络与候选服务，验证握手、身份证明、邀请和会话撤销。

交付与验收：记录协议与威胁边界；未经邀请不能取得成员权限。
裁决：[ADR-004 · 联机传输与身份](../../decisions/ADR-004-transport.md)（WSS + 邀请认证，macOS 原型 24/24）。

### M4-02 · 实现创建和加入

实施：实现局域网发现或邀请码、规则摘要、版本兼容检查与权限分配。

交付与验收：双平台进入同一 World ID；不兼容版本给出清晰原因。
实现记录（M4-02 切片，不表示 M4 完成）：[RECORD-01 · 创建与加入](RECORD-01-join.md)。
加入码与客户端入世（端点、证书、邀请合为一个可粘贴值，主场景接入权威世界）：[RECORD-06 · 加入码与客户端入世](RECORD-06-client.md)。
2026-11-15 增补在线成员名册：[RECORD-05 · 在线成员名册](RECORD-05-presence.md)。
2026-11-15 增补启动界面开房与加入：[RECORD-07 · 启动界面开房与加入](RECORD-07-rooms.md)。
2026-11-15 增补本机玩家档案：[RECORD-08 · 本机玩家档案](RECORD-08-player-profile.md)。

### M4-03 · 实现同步与重连

实施：基于序号同步事件/快照，重复命令返回同一结果，断线显示最后确认状态。

交付与验收：两端同时操作同一地块只有一次合法结果；重连不重复发奖。
实现记录（M4-03 切片，不表示 M4 完成）：[RECORD-02 · 同步与重连](RECORD-02-sync.md)、[RECORD-06 · 加入码与客户端入世](RECORD-06-client.md)（客户端接入与断线提示；开房追加访客照料码，缺失时房间照常可用）；第五轮客户端自动重连并入 [RECORD-02](RECORD-02-sync.md)。

### M4-04 · 实现世界搬迁

实施：停写、备份、恢复、更新运行代次和访问地址，旧端拒绝继续写入。

交付与验收：迁移后玩家、好友、财产连续；双写试验被阻止。
实现记录（M4-04 切片，不表示 M4 完成）：[RECORD-03 · 世界搬迁](RECORD-03-move.md)。

### M4-05 · 验证服务器部署

实施：验证 Windows/macOS/Linux 无头部署入口，记录实际支持矩阵和房主休眠行为。

交付与验收：干净部署可恢复同一世界；无中心目录时仍能凭邀请重连。
实现记录（M4-05 切片，不表示 M4 完成）：[RECORD-04 · 服务器部署](RECORD-04-deploy.md)。

### 增补切片 · 世界经济命令与面板

实施：成员在共享世界通过连接身份执行付款、市场与借贷命令，访客只读；权威按固定顺序扫描并在空闲时按自己的时钟补扫。

交付与验收：载荷不能指定他人身份，重复命令不二次记账，面板不做本地回放。
实现记录（不表示 M4 完成）：[RECORD-09 · 经济命令](RECORD-09-economy-commands.md)、[RECORD-10 · 经济面板接线](RECORD-10-economy-panels.md)。权限见 [ADR-019](../../decisions/ADR-019-economy-command-permissions.md)。

### 增补切片 · 载荷上限与每 peer 限频

实施：权威→成员的每份文档过 48 KiB 线上预算（超预算 zstd+base64），并按 peer、按请求种类限频；超限回具名拒绝，不静默丢包。

交付与验收：合法的整份摘要与最大 tail 都能送达；单个成员不能以重复请求放大权威工作。
实现记录（不表示 M4 完成）：[RECORD-02 · 同步](RECORD-02-sync.md)、[RECORD-11 · 每 peer 限频](RECORD-11-rate-limit.md)、[RECORD-12 · 摘要按收件人投影](RECORD-12-summary-projection.md)。裁决见 [ADR-026](../../decisions/ADR-026-network-payload-limits.md) 与 [ADR-027](../../decisions/ADR-027-summary-visibility.md)。

### 增补切片 · 玩家身份绑定

实施：本机保存 32 字节安装凭据，具名加入只出示由凭据与 `world_id` 派生的 HMAC 证明；权威按 `player_id` 绑定首个证明，之后必须出示同一证明。

交付与验收：他人无法凭邀请冒充已知 `player_id`；绑定跨重启保持；只读权威不新增绑定；损坏文档具名拒绝。
实现记录：[RECORD-13 · 身份绑定](RECORD-13-identity.md)。裁决见 [ADR-029](../../decisions/ADR-029-player-identity-binding.md)。

### 增补切片 · 开户赠款按成员发行

实施：开户赠款以 `player_bindings.json` 中同一世界证明为成员证据；同一安装的另一个 `player_id` 已持有 `granted` 时，权威在规则前返回 `grant_already_issued`。农场格式仍为 27。

交付与验收：同一邀请换新 `player_id` 不二次发行；不同安装各自首次发行；重启/重连不重复。
实现记录：[RECORD-14 · 赠款上限](RECORD-14-grant-limit.md)。

## 集成验收

Q2/Q3/Q5/Q6；身份材料丢失/轮换、地址变更与版本不符均有可执行恢复说明。

## 回退与边界

客户端回退兼容版本；迁移失败恢复旧服务器写入前必须关闭新端写入。

不承诺跨服资产互兑、自动全网好友发现或无限公开服务器规模。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
