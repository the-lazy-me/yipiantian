# P0 · 方向、研究与可行性

状态：仓库调查与完整策划已形成；技术原型和整体授权核验仍待执行，P0 未验收。

## 目标与交付

统一无任务自由人生、世界系统、数据权威、跨平台、三模式、低功耗和 AI 边界，给 M0 提供可执行输入。交付包括本目录之外的核心规格、研究来源、架构决定、风险登记、六项原型记录和首轮工作包。

## 顺序

1. 完成源码、规则、历史资料与权限调查，记录确切基线和冲突范围。
2. 固定世界宪章与系统职责，设计和开源初筛可相互修正。
3. 优先核验原项目和采用资产的权利，锁定会阻塞前期工程的来源。
4. 开展 Mac、三模式、无头、数据身份、推理与事务六项隔离原型。
5. 根据结果决定运行形态、存储和迁移路径，修改对应 ADR 与契约。
6. 审查 M0 工作包的输入、范围和验收，逐项确认必要条件已满足再开工。

## 验收

产品原则可用于裁决具体机制；各状态只有一个权威拥有者；候选依赖有直接来源和采用边界；原型有真实记录或明确回退，阻塞 M0 的事项已解决；M0 可依据现有计划实施而无需再次询问已知目标。

本次完成文档不能代替六项原型。缺设备、授权材料或失败结果明确记入[可行性](../../feasibility/P0-FEASIBILITY.md)和[风险](../../decisions/RISKS.md)，只阻塞相关工作，不停止无依赖的研究。
