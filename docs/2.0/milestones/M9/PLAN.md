# M9 · 受限端云模型调度

状态：计划中，未验收。前置：P0 推理试验；M3 事件；M2 能效状态机。

## 阶段成果

提供可完全关闭、有预算和可降级的混合 AI 服务。

权威规格：[相关设计](../../06-AI-SYSTEM.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M9-01 · 选择代表模型

实施：核验权重与推理库许可，在 Mac M4/M4 Pro 和 Windows 对照中文任务、内存和耗时。

交付与验收：记录实际设备与模型摘要；没有合格本地模型则保留规则模式。

记录：[RECORD-01-model-selection](RECORD-01-model-selection.md)（2026-11-15，macOS 初筛与单样本 smoke，未验收；Qwen3-4B Q4_K_M 为默认候选，Q4/Q8 的本机吞吐、内存与中文意图 JSON；Windows、MLX、完整任务集、质量评分、游戏共存与能耗未测）。调查：[MODEL-CANDIDATES](../../research/MODEL-CANDIDATES.md)。

### M9-02 · 建立任务协议

实施：类型、可见上下文、输出意图、状态版本、期限与取消标识。

交付与验收：模型响应只能形成建议，过期/跨世界结果拒绝。

记录：[RECORD-02 · 任务协议](RECORD-02-protocol.md)（2026-11-15，已实现，未验收；三类任务、15 个可见上下文字段白名单、四种意图、8192 字节上下文与 32768 字节响应上限、`cancel_id` 缺省即自身，过期／取消／跨世界／版本不符只返回稳定拒绝原因，响应只作建议，不写世界）。决定：[ADR-020](../../decisions/ADR-020-model-task-scheduling.md)。

### M9-03 · 实现资源调度

实施：懒加载、单队列起步、输出与上下文限制、缓存、超时、卸载和休眠联动。

交付与验收：资源上限实际生效，取消后不继续后台循环。

记录：[RECORD-03 · 单队列调度](RECORD-03-scheduler.md)（2026-11-15，已实现，未验收；注入式后端、默认 8 的单队列串行 `poll`、deadline 超时、取消、60 秒闲置卸载与 `enabled=false` 零加载零生成；尚未接入游戏运行路径、真实模型、线程后端与休眠联动）。

### M9-04 · 实现云端可选路径

实施：授权、最小上下文、费用预留、实际用量记录与硬预算。

交付与验收：断网/额度耗尽自动回退；并发请求不能越过预算。

本地后端增补（不取代云端路径）：[RECORD-04](RECORD-04-llama-backend.md) 已接入默认关闭的 llama.cpp 进程后端与调度器 `poll/abort` 钩子；云端授权、预算与回退仍未实现。

记录：[RECORD-06 · 云端预算与回退](RECORD-06-cloud-budget.md)（2026-11-16，切片已实现，未验收；`model_budget.gd` 的授权开关、估算预留、只对 `ok` 计费、周期切换保留未结算预留与有界事件日志，`model_fallback.gd` 的断网/耗尽确定性回退）。决定：[ADR-031](../../decisions/ADR-031-cloud-model-budget.md)。注意：这只是预算与回退规则落地，**真实云接入仍缺**——没有供应商客户端、密钥、网络、持久化、UI 或调度器接线。

### M9-05 · 评估可靠性

实施：恶意提示、模型崩溃、加载失败、长回复、GPU 竞争与深度休眠。

交付与验收：关闭全部模型仍可种田交易，能效回归有配对证据。

实现记录（第一部分，不表示 M9-05 完成）：[RECORD-05 · 可靠性评估](RECORD-05-reliability.md)（提示注入结构边界、异常输出、后端/调度器故障注入、资源边界与 1000 任务稳定性；GPU 竞争、深度休眠、真实模型质量与 Windows 未测）。

## 集成验收

Q4/Q8/Q10；推理吞吐与游戏可用性分开报告，不以模型可运行证明适合常驻。

## 回退与边界

停用模型后端并取消队列，世界继续规则行为，清理临时上下文不删世界事实。

不为每位 NPC 常驻模型，不默认下载权重或开启付费云调用。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
