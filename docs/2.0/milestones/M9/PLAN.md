# M9 · 受限端云模型调度

状态：计划中，未验收。前置：P0 推理试验；M3 事件；M2 能效状态机。

## 阶段成果

提供可完全关闭、有预算和可降级的混合 AI 服务。

权威规格：[相关设计](../../06-AI-SYSTEM.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M9-01 · 选择代表模型

实施：核验权重与推理库许可，在 Mac M4/M4 Pro 和 Windows 对照中文任务、内存和耗时。

交付与验收：记录实际设备与模型摘要；没有合格本地模型则保留规则模式。

### M9-02 · 建立任务协议

实施：类型、可见上下文、输出意图、状态版本、期限与取消标识。

交付与验收：模型响应只能形成建议，过期/跨世界结果拒绝。

### M9-03 · 实现资源调度

实施：懒加载、单队列起步、输出与上下文限制、缓存、超时、卸载和休眠联动。

交付与验收：资源上限实际生效，取消后不继续后台循环。

### M9-04 · 实现云端可选路径

实施：授权、最小上下文、费用预留、实际用量记录与硬预算。

交付与验收：断网/额度耗尽自动回退；并发请求不能越过预算。

### M9-05 · 评估可靠性

实施：恶意提示、模型崩溃、加载失败、长回复、GPU 竞争与深度休眠。

交付与验收：关闭全部模型仍可种田交易，能效回归有配对证据。

## 集成验收

Q4/Q8/Q10；推理吞吐与游戏可用性分开报告，不以模型可运行证明适合常驻。

## 回退与边界

停用模型后端并取消队列，世界继续规则行为，清理临时上下文不删世界事实。

不为每位 NPC 常驻模型，不默认下载权重或开启付费云调用。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
