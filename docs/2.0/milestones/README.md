# 里程碑执行与证据通用约定

本页适用于 P0、M0–M13，具体范围、依赖与验收在各阶段 PLAN 中维护；阶段命名和关键路径以[路线图](../03-ROADMAP.md)为准。

## 执行顺序与优先级

每个 PLAN 顶部列明进入条件，工作包按编号顺序推进；输入已固定、互不修改同一状态的研究或内容工作可以交错。涉及数据、权限、许可和规则契约的阻塞项优先于内容扩量。当前项目遵守主代理独立执行约定，交错工作不等同授权并行代理。

阶段开始前核对最新代码、前置成果和风险，按真实变化调整工作包。若仅完成隔离原型，标为原型；正式实现未集成、缺少必需平台或失败路径证据时保持待验收。不能靠缩减验收文字把失败阶段改成完成。

## 证据归档

实际执行后在对应阶段目录保存验收记录，包含固定提交、数据/规则版本、构建或资源摘要、环境、输入样本、操作步骤、结果、失败和未覆盖范围。性能记录必须写明配对基线与测量条件，机制实验保存种子和参数，资产记录连接可编辑源与实机对照。

大体积原始日志与视频遵循既有本地留档约定，正式正文保留复核所需的结论和方法，不能只链接不可取得的个人路径。只有实际生成证据后才创建完成记录；本轮规划不预建空验收模板。

实现者完成自检后，按[质量门槛](../09-QUALITY-GATES.md)复核可观察行为。通过的功能、尚未解决的问题与发行状态分别报告；提交、已验收和已发布不互相替代。
