# M2 · 三模式与深度休眠

状态：计划中，未验收。前置：M1 双平台窗口；P0 宿主与能效对照。

## 阶段成果

在同一世界中切换观赏、轻量桌面和全量游戏，建立低功耗常驻成果。

权威规格：[相关设计](../../04-ARCHITECTURE.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M2-01 · 裁决运行形态

实施：用同场景比较单 Godot 与原生轻量外壳；计入空闲内存、交互恢复和维护成本，更新 ADR-002。

交付与验收：有配对测量与具体选择，未获支持的平台能力使用公开回退。

### M2-02 · 实现模式状态机

实施：定义输入结束、待确认命令、资源释放、恢复同步与声音行为；三模式只访问一个权威写入者。

交付与验收：快速来回切换不重复提交，不丢工具取消，不产生分叉存档。

### M2-03 · 完成双平台桌面适配

实施：Windows 保持图标下层与原输入边界；Mac 验证 Spaces、Dock、全屏应用与多屏。

交付与验收：不会抢焦点或吞掉桌面操作；不支持嵌入时可正常观赏与主动打开交互。

进行中记录：[macOS 桌面嵌入验收](RECORD-01-macos-embed.md)（桌面层、输入门禁与恢复已核验；多屏、Spaces 与导出包待补）。

### M2-04 · 实现休眠与预算

实施：锁屏/熄屏/遮挡停止非必要绘制，取消背景推理，释放可恢复资源；恢复先结算或同步。

交付与验收：休眠期间无持续绘制，恢复世界状态正确；预算按实测固定。

进行中记录：[macOS 锁屏与熄屏停绘制](RECORD-03-sleep.md)（自动化验证完成；真实锁屏/熄屏事件与遮挡未实测）。

### M2-05 · 验证长期驻留

实施：按能效规范完成配对短测、连续驻留和休眠恢复；记录 CPU/GPU/内存/功率各自口径。

交付与验收：无持续资源增长，模式差异可测；缺测设备不得标达标。

## 集成验收

Q1–Q4；首个阶段成果 Desktop Alpha，必须能在不联网、不用 AI 时完整种田。

不以换渲染器或降低画面冒充低功耗达标，不接入复杂经济。
