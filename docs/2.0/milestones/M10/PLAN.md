# M10 · 人格、记忆与自主居民

状态：计划中，未验收。前置：M9 调度；M7 市场；银行角色依赖 M8。

## 阶段成果

让居民在自己的资源和关系约束下生活，形成 AI Society Beta。

权威规格：[相关设计](../../06-AI-SYSTEM.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

当前进展：人格与有界记忆见 [RECORD-01](RECORD-01-memory.md)，三人名册与派生人格见 [RECORD-02](RECORD-02-roster.md)；自主行动（M10-03 起）尚未开始。下面的工作包编号保留计划顺序，实际已落地切片以记录为准。

### M10-01 · 建立角色基线

实施：从林婶、许伯、阿舟的现有故事提取已知设定，定义资源、偏好与日程。

交付与验收：原有身份不被随机覆盖；关闭模型时仍有一致规则行为。

### M10-02 · 实现有限记忆

实施：事件事实、主观评价和临时对话分层，按重要性压缩，保留承诺来源。

交付与验收：传闻不变成资产事实，删除私人对话不破坏公开账本。

### M10-03 · 接入自主行动

实施：有限目标选择、状态校验、冷却与失败后等待，先交易再扩展拜访。

交付与验收：阿舟用真实预算采购；重复或过期意图不重复成交。

### M10-04 · 扩展角色与社会事件

实施：商人/银行家/官员使用各自权限；生成叙事仅解释已发生事件或明确提议。

交付与验收：NPC 邀约可拒绝，模型不凭叙述改变权属。

### M10-05 · 长期行为评估

实施：无人观看、稀少交易、关系冲突与模型停用对照，测循环、成本与人格稳定性。

交付与验收：无无限自聊和无限交易；成本与记忆规模受限，角色自然度有实际体验记录。

## 集成验收

不承诺模拟完整人类意识，不以长文本数量衡量居民质量。
