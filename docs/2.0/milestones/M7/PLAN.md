# M7 · 供求驱动的动态市场

状态：计划中，未验收。前置：M3 事务；M5 资产权限；M6 产出事件。

## 阶段成果

建立有限库存、真实消耗与可解释价格的市场。

权威规格：[相关设计](../../systems/economy-finance.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M7-01 · 建立经济初始条件

实施：确定少量商品、货币发行与回收、Demo 内容转换和库存所有权。

交付与验收：所有初始资源有来源，重复转换不增发。

记录：[RECORD-01-economy-initial](RECORD-01-economy-initial.md)（2026-11-15，切片完成，未验收；六种作物商品、一次性开户发行、Demo 开库存登记与幂等账本；报价、订单、回收项与网络接入未覆盖）。决定：[ADR-010](../../decisions/ADR-010-economy-initial-conditions.md)。

### M7-02 · 实现报价和订单

实施：规则商人有限预算，玩家限价单、资源预留、撤单与到期。

交付与验收：预留不超库存/余额；挂牌与成交价格区分。

记录：[RECORD-02-market-orders](RECORD-02-market-orders.md)（2026-11-15，切片完成，未验收；六种商品限价单、托管式商品/现金预留、规则商人报价与预算、撤单、确定性 UTC 到期与耐久订单记录；撮合、部分成交、费用与网络接入未覆盖）。决定：[ADR-011](../../decisions/ADR-011-market-orders.md)。

### M7-03 · 实现撮合与交割

实施：价格/接收序号排序，部分成交、费用、资金商品同时提交。

交付与验收：并发撤单和成交、断线重试均无双花或单边交付。

### M7-04 · 建立有限物流

实施：选两处市场验证在途货物、成本和交付，不先做全区域运输网。

交付与验收：在途货不能重复出售，交付事件可追溯。

### M7-05 · 运行供需实验

实施：普通生产、歉收、囤积、无人交易和循环套利对照，公开调参依据。

交付与验收：货币商品守恒，无已知零成本无限循环；玩家可选择自给生活。

## 集成验收

Q5–Q7；市场关闭 AI 时仍能独立运转，价格变化有库存与需求证据。

## 回退与边界

停止接受新订单、释放未成交预留，已成交记录保持可查询；规则回退使用一致快照。

不引入证券、跨服兑换或必须每天接订单的成长结构。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
