# M7 · 供求驱动的动态市场

状态：计划中，未验收。前置：M3 事务；M5 资产权限；M6 产出事件。

## 阶段成果

建立有限库存、真实消耗与可解释价格的市场。

权威规格：[相关设计](../../systems/economy-finance.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M7-01 · 建立经济初始条件

实施：确定少量商品、货币发行与回收、Demo 内容转换和库存所有权。

交付与验收：所有初始资源有来源，重复转换不增发。

记录：[RECORD-01-economy-initial](RECORD-01-economy-initial.md)（2026-11-15，切片完成，未验收；六种作物商品、一次性开户发行、Demo 开库存登记与幂等账本；报价、订单、回收项与网络接入未覆盖）。决定：[ADR-010](../../decisions/ADR-010-economy-initial-conditions.md)。

### M7-02 · 实现报价和订单

实施：规则商人有限预算，玩家限价单、资源预留、撤单与到期。

交付与验收：预留不超库存/余额；挂牌与成交价格区分。

记录：[RECORD-02-market-orders](RECORD-02-market-orders.md)（2026-11-15，切片完成，未验收；六种商品限价单、托管式商品/现金预留、规则商人报价与预算、撤单、确定性 UTC 到期与耐久订单记录；撮合、部分成交、费用与网络接入未覆盖）。决定：[ADR-011](../../decisions/ADR-011-market-orders.md)。

### M7-03 · 实现撮合与交割

实施：价格/接收序号排序，部分成交、费用、资金商品同时提交。

交付与验收：并发撤单和成交、断线重试均无双花或单边交付。

记录：[RECORD-03-matching](RECORD-03-matching.md)（2026-11-15，切片完成，未验收；确定性撮合扫描、价格时间优先、部分成交、maker 成交价、每笔 1 COIN 费用销毁、原子交割与耐久成交记录；物流、网络接入与费用调参未覆盖）。决定：[ADR-012](../../decisions/ADR-012-matching-settlement.md)。

### M7-04 · 建立有限物流

实施：选两处市场验证在途货物、成本和交付，不先做全区域运输网。

交付与验收：在途货不能重复出售，交付事件可追溯。

记录：[RECORD-04-logistics](RECORD-04-logistics.md)（2026-11-15，切片完成，未验收；两处固定市场、在途托管、固定运费销毁、确定性到达扫描与耐久交付事件；跨区域路网、承运人、保险、风险、取消与网络接入未覆盖）。决定：[ADR-013](../../decisions/ADR-013-limited-logistics.md)。

### M7-05 · 运行供需实验

实施：普通生产、歉收、囤积、无人交易和循环套利对照，公开调参依据。

交付与验收：货币商品守恒，无已知零成本无限循环；玩家可选择自给生活。

记录：[RECORD-05-supply-demand](RECORD-05-supply-demand.md)（2026-11-15，实验完成，未验收；普通生产、歉收、囤积、只有单边订单、商人价差、两市场运费循环、玩家往返与自成交、关闭市场自给、订单上限与重复周期；合成需求假设、具名口袋进食缺口与归档缺失已记录）。

### 市场界面（横切切片）

实施：单机市场面板、钱包与报价、下单／撤单／发货／交付意图、权威扫描与共享世界命令。

交付与验收：玩家可在单机完成规则操作；规则失败不改显示余额。单机产出归属已由 [M7-07](#m7-07--单机产出归属) 裁决（ADR-015），市场能读到本机口袋货物；完整单机闭环（播种→收获→厨房→本地成交→借贷→建造→重开）由 [M13 RECORD-13](../M13/RECORD-13-peaceful-life.md) 的 `PEACEFUL_LIFE_TEST` 覆盖。

记录：[RECORD-06-market-panel](RECORD-06-market-panel.md)（2026-11-15，切片完成，未验收；面板、主场景接线与 31 项视图检查；网络权限已由 [M4-09](../M4/RECORD-09-economy-commands.md) 接入，美术与 Windows 实机未覆盖）。

### M7-07 · 单机产出归属

实施：具名收获进入本机玩家口袋，厨房、动物与邻里篮子读取同一口袋；匿名路径保留共享库存。

交付与验收：市场能读到本机货物；口袋不足时厨房、动物与篮子原子失败；旧档共享库存原样保留、不迁移。

记录：[RECORD-07-pantry-ownership](RECORD-07-pantry-ownership.md)（2026-11-15，切片完成，未验收；口袋视图、复制/提交保留、显示视图与持久快照分离；旧档库存不可见、网络与 Windows 实机未覆盖）。决定：[ADR-015](../../decisions/ADR-015-single-player-produce-ownership.md)。

### M7-08 · 商人流动性

实施：开市一次性授予六种商品库存，规则商人以参考价 ±1 挂稳定 id 的滚动双向报价，订单表固定 12 行。

交付与验收：单机能与商人双向成交；重复开市不二次授予；现金/库存耗尽停止补充、回笼后恢复；旧世界首次扫描补授予。

记录：[RECORD-08-merchant-liquidity](RECORD-08-merchant-liquidity.md)（2026-11-15，切片完成，未验收；一次性授予、滚动报价、自成交重复科目修复与守恒口径；动态调价、AI 做市与长寿命耗尽未覆盖）。决定：[ADR-016](../../decisions/ADR-016-merchant-liquidity.md)。

### M7-09 · 订单与物流归档

实施：订单表与发货表达到 256 行时淘汰最旧的已关闭／已交付行，保留单调归档计数；成交与交付证据允许引用已归档行。

交付与验收：长寿命世界不再永久 `order_limit`；在途与未成交行永不淘汰；归档后守恒与对账不变。

记录：[RECORD-09-archive](RECORD-09-archive.md)（2026-11-15，切片完成，未验收；订单/发货/交付三类证据表归档、引用容错与计数；网络、UI 与真实长寿命世界未覆盖）。决定：[ADR-018](../../decisions/ADR-018-order-archive.md)。
