# M3 · 无图形权威世界服务

状态：计划中，未验收。前置：M0 规则核心；阶段交付仍以 M2 成果稳定为前提。

## 阶段成果

让世界脱离客户端独立推进，并建立可恢复的模拟实验入口。

权威规格：[相关设计](../../04-ARCHITECTURE.md)；统一证据标准：[质量门槛](../../09-QUALITY-GATES.md)。本页只维护实施范围与顺序。

## 实施步骤与工作包

### M3-01 · 建立无头入口

实施：从规则和存储启动最小世界，检查所有资源依赖，禁止加载主 3D 场景。

交付与验收：无 GPU 环境可播种、推进、收获与保存，记录实际资源占用。
实现记录（M3-01 切片，不表示 M3 完成）：[RECORD-01 · 无头入口](RECORD-01-headless.md)。

### M3-02 · 建立事件调度

实施：按下一事件唤醒；区分单机补算和服务器时间，长区间分段执行。

交付与验收：连续运行与长离线补算结果一致，回拨不负增长。
实现记录（M3-02 切片，不表示 M3 完成）：[RECORD-02 · 事件调度](RECORD-02-events.md)。

### M3-03 · 实现提交与恢复

实施：按 ADR-003 选择事务存储，绑定命令结果、状态变更和事件序号，增加快照恢复。

交付与验收：在提交前/中/后终止进程并恢复，无重复产出和单边写入。
实现记录（M3-03 切片，不表示 M3 完成）：[RECORD-03 · 提交中断与恢复](RECORD-03-commit-recovery.md)。

### M3-04 · 建立模拟实验入口

实施：用固定种子和可控时间运行多个小世界，输出资源与事件摘要。

交付与验收：实验可重复，无头结果与规则夹具一致，日志不含个人数据。
实现记录（M3-04 切片，不表示 M3 完成）：[RECORD-04 · 多世界实验入口](RECORD-04-lab.md)。

## 集成验收

Q1/Q2/Q5；无人连接时服务低频运行，客户端关闭不影响独立服务器。

## 回退与边界

恢复匹配版本快照和事件尾部；新写入格式先在隔离世界使用。

不预建大规模集群、全区块常驻 3D 或复杂微服务。

执行顺序、优先级与证据格式遵循[里程碑通用约定](../README.md)；本阶段尚无实际验收记录。
