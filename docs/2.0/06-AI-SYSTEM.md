# NPC、商人与混合 AI 设计

状态：目标设计；推理框架、模型和预算待实测。AI 不承担[世界规则](04-ARCHITECTURE.md)的最终裁定。

## 三层决策

规则层提供作息、资源需求、行动合法性与无模型回退；端侧受限小模型处理短对话、有限意图选择、记忆摘要；可选云端大模型处理较复杂关系推理、长对话或低频计划。任务按复杂度、隐私、延迟与预算路由，不能每个 NPC 每帧调用模型。

先建设可独立运转的规则居民，再让模型在可选动作中提出建议。模型返回结构化意图、理由、所依据的状态版本和有效期限。执行前再次核对预算、权限、库存、距离或合同条件；过期建议丢弃或重新规划。对话里“已经付款”只有在交易提交后才可呈现为事实。

## 居民状态与记忆

人物由稳定 ID、人格偏好、生活资源、关系、日程、当前目标和有限记忆组成。林婶、许伯、阿舟沿用既有身份与故事作为首批样本，不凭模型生成重写他们的既有经历。

记忆分为可验证事件、人物的主观评价和临时对话。事件引用世界事件 ID，主观评价标记来源与可信度；传闻不能变成账本事实。按重要性和时间压缩，保存关键关系与承诺，删除不再必要的原始对话。世界迁移携带必要 NPC 状态，隐私导出按权限过滤其他玩家私有内容。

自主性由有限目标驱动：备餐、休息、照料、补库存、拜访。目标失败可以换方案或等待，不能无限自问自答。相同居民短时间重复动作进入冷却或由规则层终止循环，记录失败原因供调试。

## 商人例子

阿舟读取自己的货币、库存、可达市场和公开价格历史，拟定采购上限与数量。规则层检查资金，创建带有效期报价并预留资源；成交后由账本确认付款和交货。市场价格上涨时他可以改未来报价，不能撤回已成交合同。玩家不买时他可与其他居民交易，不能生成强制玩家消费任务。

银行家可解释贷款条款并建议报价，利率和授信权限由金融规则限制。官员可总结案件材料，裁决必须使用确定的权限与证据程序。居民的聪明程度不带来凭空获得资源的特权。

## 端侧资源管理

本地模型按需加载，默认单个推理队列起步；上下文、输出长度、线程、并发、内存、占用时间和 GPU 竞争均可限制。数值由 P0 的 M4/M4 Pro 与 Windows 样机实测后锁定，当前无已验证的常驻内存或瓦数承诺。

用户交互优先于背景摘要，深度休眠取消可取消任务并卸载模型。取消后迟到结果不得作用于新世界或新会话。达到内存、温度、耗时或队列预算时退回规则行为；重试有次数与间隔限制。缓存按模型版本、提示版本、上下文摘要及规则版本失效。

`llama.cpp` 是跨平台候选，MLX 是 Apple Silicon 对照候选；推理库许可证与具体权重许可证分别核验。模型下载、首次启用与云服务配置需要玩家明确操作，发行包不默默携带来源不明权重。

## 云端成本与隐私

云端默认关闭。启用前展示供应商、发送的数据类型、预算与停用方式；仅发送角色所需上下文，不上传完整存档、联系人列表或身份密钥。按调用前估算预留预算，完成后记实际用量，余额不足时不启动新请求；并发请求共享预算，超时也要处理供应商可能已计费的状态。预算与回退规则已在 [M9-04 记录](milestones/M9/RECORD-06-cloud-budget.md)和 [ADR-031](decisions/ADR-031-cloud-model-budget.md) 冻结为纯规则；真实云接入、持久化与界面仍未实现。

用户可只用规则 NPC、只启用端侧或允许混合调度。断网、配额耗尽、模型无响应时居民继续生活，界面简短说明对话能力变化，不反复弹窗催用户充值。

## 输入与行为边界

聊天、物品名称、留言和外部文本都作为世界数据，不能覆盖系统权限。模型可调用的动作来自限定清单，禁止文件读写、任意网络、系统命令和直接数据库更新。角色只获得可见信息，不因模型上下文共享泄露其他玩家私信或秘密资产。

记录请求类型、模型及提示版本、预算、验证结果和实际行动事件，日志默认不保存敏感原文。自动评估覆盖诱导越权、虚构成交、恶意提示、循环交易、记忆污染和跨世界迟到响应；审美与角色自然度仍需实际体验。
