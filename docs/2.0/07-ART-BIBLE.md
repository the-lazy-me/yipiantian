# 风格、资产生成与声音指南

状态：沿用已确认的视觉方向；2.0 新资产和跨平台资源预算待生产验证。

## 唯一风格依据

正式基准为[风格基准 v1](../design-baseline/style-guide.md)的 A 工笔淡彩全景与 A 淡彩青菜；[美术方向](../design-baseline/art-direction.md)解释形体与笔触，[来源](../design-baseline/sources.md)保存参考归属。B/C 等历史探索不重新成为待选方案。2.0 扩展地区与人物时保持这一视觉语言，不覆盖获选原图。

场景采用架空宋明江南生活气质：灰瓦粉墙、木竹、青石、陶器、菜畦与水岸。体积圆润概括，表面保留选择性细线、淡彩层次和适量积色。植物、木头与陶器各有材质本色；不使用统一塑料高光、摄影级密纹或全屏旧纸黄滤镜。

## 三模式中的表现

观赏重视全景的呼吸感、昼夜和少量生活动态；轻量模式优先清楚的可操作对象与状态；全量模式允许近看与旋转，模型背面、连接与接地必须成立。同一资产不同细节档保留识别特征，不能把低功耗等同于破面或失去用户选择的笔触。

UI 继续使用项目内汇文明朝体与既有淡彩风格。场景是主体，操作信息按当前行为出现；市场、银行和治理页面显示必要数量、费用、权限与风险，不把技术架构、模型版本或推理链塞进普通生活流程。状态不能仅靠颜色区分，文字缩放与键鼠可达性在 M1/M2 验证。

## 资产生产顺序

按[资产工作流](../asset-workflow.md)与[Tripo 工作流](../tripo-workflow.md)执行。每个资产先明确用途、观察距离、结构与动画需求，再使用固定参考生成单体图并检查；图转模型后保留不可变原件，Blender 处理尺度、枢轴、连接、UV 和必要骨骼，Godot 验证真实灯光与镜头。

精确道路、地块、桥接头和可参数化构件优先精确建模；有机形体、装饰和作物可使用生成结果再整理。生长阶段共用品种和根部定位，只有连续形变需要时才要求同拓扑。AI 生成的多视图不天然一致，正式模型应检查所有可见侧面。

每件正式资产保存来源、参考职责、实际模型/工具版本、实际提示、后处理和导出位置。详细商业制作过程沿用本地留档约定；入库的来源与使用依据应足以让其他维护者审查，不能只指向不存在的个人目录。费用、令牌与服务原始回显不进入公共文档。

## 代表资产与验收

首轮代表集为一种作物三阶段、一间住宅、一段木/竹构件、一位居民及一组环境声音。逐项检查轮廓、比例、接地、正背面、相邻接触、日夜可读性、LOD 切换与实际内存。先建立这些样本的实测预算，再扩大内容数量；不按统一面数机械削减所有资产。

三维源放 `ArtSource/`，正式资源进入 `Game/art/`，文本配置与导入元数据随资源维护。生成图不是实机截图，模型能导入也不等于风格获验收。性能测量必须使用实际资源组合与镜头，不把单体三角形减少直接宣称为整机省电。

## 声音与音乐

声音围绕风、水、鸟虫、脚步、农具、木竹与远处生活声构建层次。交互声短而可辨，背景音乐稀疏，不用循环高强度提示催收获。观赏可静音，失焦与休眠遵循现有声音策略；恢复不同时爆发积压音效。

生成音频记录来源与使用条件，保留可编辑工程或处理链。导入前检查削波、循环接缝、突发峰值与频谱刺耳区，实际设备试听；音量和响度目标按代表集确定。人物语音为候选，可先以文字加少量非语言声表达，避免引入大体积和持续合成开销。
