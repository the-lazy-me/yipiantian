# ADR-002 · 三模式采用何种运行形态

状态：拟议，P0-R2 完成后裁决。日期：2026-11-14。

## 目标与现状

三模式共享世界、显著降低日常资源消耗，同时保留现有 Godot 画面与 Windows 宿主。现有观赏节流、停绘制与缓存释放已有历史短测，但尚未证明跨平台轻量模式可达到预算。

## 两个有效候选

A：单 Godot 运行时承载三模式，隐藏场景并按需释放资源。优点是规则和资源路径集中、切换简单；风险是引擎及资产的最低驻留开销仍高。

B：原生轻量外壳与规则服务，按需启动 Godot 全量呈现。优点是可移除日常 3D 常驻成本；代价是 IPC、进程生命周期、双平台维护和恢复复杂度。只有实测收益覆盖这些代价才采用。

## 裁决方法

在相同世界、画面与输入下比较启动/恢复延迟、工作集、GPU、唤醒、增量功率及实现复杂度。先给 A 做最小完整优化，再以 B 的代表交互验证收益。判断使用配对测量与用户可感知响应，不预设“原生必然更省电”。

若 B 不能提供足够收益，采用 A；若两者均未达目标，保留窗口版并继续隔离高开销资源，不宣称 M2 完成。Mac 桌面嵌入能力另行验证，失败可回退观赏窗口，不改变世界契约。

验收要求见[平台能效](../architecture/PLATFORM-ENERGY.md)；当前无选定结论、无性能通过记录。
