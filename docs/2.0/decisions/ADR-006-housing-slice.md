# ADR-006 · 住宅首版：先占地与工期，材料留到市场

- 状态：采纳（2026-11-15）
- 关联：[M5-04 住宅与院落](../milestones/M5/PLAN.md)、[社会与住宅](../systems/society-housing.md)、[活动经济设计](../02-GAME-DESIGN.md)

## 背景

M5-04 要求“蓝图预览、用地检查、材料检查、确认施工、完成与使用”，验收含“相同占地并发建造只成功一次、材料无复制、房屋迁移后重建”。当前世界没有任何建材来源：经济只有作物口袋与公共库存，交易与市场是 M7，材料账本依赖它。现在凭空发明一套木料／石料产出，会立刻与 M7 的定价、产出和存量规则冲突。

## 决定

1. **首版先实现生命周期与占地**：蓝图目录、固定宅基槽位、建造占用与工期、拆除。建造命令与收获、赠送走同一条权威命令通道与同一本幂等账本，因此同一槽位的并发建造只有一次成功。
2. **首版不引入材料账本**：建造不扣任何资源，也不产生可回收材料。“材料无复制”这一条在本版没有可被违反的对象，随 M7 交易一起实现；到那时再决定建材是独立资源还是作物折算，并补上预留、取消退回与拆除回收的分支。
3. **槽位而不是任意坐标**：宅基用固定命名槽位（`yard_a`…`yard_f`），每个槽位在目录里带名称与建议摆放位置。任意坐标放置需要几何重叠、接地与通行检查，属于院落编辑器（后续切片）；固定槽位先给出可验证的占位语义。
4. **归属与权限**：建造者即房主，只有房主能拆除；所有具名成员都能建造，匿名成员不能（没有可归属的产权）。不使用协作授权：授权管田地工作，不管住宅。

## 后果

- 玩家现在可以在村落里占下宅基、等待工期、拆除重建，住宅因此先有“位置与时间”，再有“材料与外观”。
- 记录必须明确写出“材料账本未实现”，不能把本切片当成 M5-04 验收完成。
- M7 引入材料时，建造命令需要新增材料字段与预留阶段；已存在的住宅不回溯收费。
- 固定槽位的数量与位置写进目录，扩容是数据改动，不是规则改动。
