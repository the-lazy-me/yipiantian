# 架构决策与风险入口

状态“已确定”用于已被用户明确要求的长期边界；“拟议”用于尚待原型的技术选择；“被替代”保留旧理由并链接新决定。工程现状不从 ADR 推断，仍以代码与[基线](../research/BASELINE.md)为准。
