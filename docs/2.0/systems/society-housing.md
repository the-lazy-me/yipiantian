# 社交、自建房间与自建住宅

状态：目标设计；已有本地邻居故事不等同多人社交。数据归属以[数据契约](../05-DATA-AND-NETWORK.md)为准。

## 自建房间的生活边界

单机世界无需账户服务；局域网房间支持朋友临时相聚；独立服务器适合持续村落。创建房间时明确世界类型、规则版本、可见范围、访问方式和谁保存数据。房主关闭客户端但服务器仍在时世界继续；房主电脑休眠且无独立服务时房间离线。

加入流程为查看规则、验证世界身份、确认邀请、选择显示资料、取得明确权限。房主、管理员、成员、访客分开，不能把“是好友”直接等同“可收获所有田”。邀请可失效和撤销；重新加入沿用同一玩家身份与既有财产。

## 自由社交

首轮能力为邀请、互访、赠送、留言和照料协作。赠送在发送方扣除与接收方入账之间保持原子性；收件箱满时不丢物，礼物退回有唯一事件。留言可删除或屏蔽，玩家可关闭陌生人联系。未读摘要合并呈现，不为提高活跃度持续打扰。

互助权限按访问、浇水、收获、建设分别授予，可限定区域和有效期。所有者可以撤销未来操作；已经完成的合法交易不能因关系解除随意回滚。共同建设的材料、建筑和拆除所得在开始前约定归属。

有限偷菜作为可选玩法：所有者与参与者均接受房间规则，保护基本收成，按批次与时间窗限制损失。被偷结果可解释且可追溯，关闭玩法不会失去基础交易与社交权利。默认和平家园不开放偷菜；好友关系不自动构成偷菜同意。

## 房屋与院落

建设由蓝图预览、用地检查、材料检查、确认施工、完成与使用构成。先沿用现有布局与构件能力，在 M5 验证私人院落内的住宅组合与装饰，M11 再接入公共地籍、租赁和组织土地。

蓝图描述占地、入口、基础高度、模块连接和材料成本；预览不扣材料。确认时一次预留材料与地块，取消施工按明确进度退回可回收部分。移动、拆除、维修分别有规则，不能通过反复摆放复制建材。建筑风格来自既有江南基线，不由规划自动引入无限体素或任意物理破坏。

房屋应有可读入口、相邻通行空间与合理接地关系。第一版优先院落外观和有限内部功能；无缝大规模室内世界为候选。保存记录蓝图与参数而非场景节点，缺失显示资源不丢失住宅所有权。

## 关系与隐私

联系人使用稳定 Player ID，昵称可以改。私人笔记、NPC 对话和公开公告分别存储；导出仅包含玩家有权取得的内容。服务器地址迁移后保持身份连续，在线发现依赖可达入口，不承诺离线或断网下实时显示朋友状态。

房间管理可禁言、限制交互或封禁，并记录原因和期限。玩家退出时保留可导出的个人资料、联系人及财产摘要；共有资产和未结合同按原世界规则处理。迁往其他世界不复制共有资金。

## 验收故事

Windows 玩家邀请 Mac 玩家共同浇田，对方能照料但不能收走作物；权限撤销后旧会话无法继续操作。两人同时确认同一位置建房，仅一项生效，另一项保留材料。断线重发赠送不重复入账。房间搬家后昵称与好友关系连续；只观赏和不参与偷菜的玩家仍能生活。
